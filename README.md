# NETWORKWALKS-B084-WK3 PM1 and PM2


🔐 **Cybersecurity Hands-On Lab Completed | Week 3 – B084 | John the Ripper**

Another milestone in my cybersecurity learning journey! 🚀

As part of **Week 3 – B084 Cybersecurity Training**, I successfully completed a hands-on **PDF Password Recovery Lab** using Kali Linux in an Oracle VirtualBox environment.

The objective was to recover the password of an encrypted PDF in an authorized training environment, unlock the document, and capture the lab flag.

🛠️ **Tools & Technologies Used:**
- Kali Linux
- John the Ripper
- pdf2john
- RockYou Wordlist
- qpdf
- Oracle VirtualBox

💻 **What I Accomplished:**

✅ Extracted the password hash from an encrypted PDF using pdf2john.

✅ Performed a dictionary-based password recovery attack using John the Ripper.

✅ Successfully recovered the password using the RockYou wordlist.

✅ Decrypted the protected PDF using qpdf.

✅ Verified that the document was no longer encrypted.

✅ Successfully captured the lab flag! 🏁

💡 **Key Takeaways:**

This hands-on experience helped me better understand password hashing, dictionary attacks, password security, and how weak passwords can expose protected information.

I also gained more confidence working with the Linux terminal, troubleshooting errors, installing dependencies, and using cybersecurity tools in a practical lab environment.
